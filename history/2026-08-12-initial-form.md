# 2026-08-12 個人情報入力フォームの作成・改善

## 概要

個人情報に特化した入力フォーム（静的 HTML / CSS / JS）を新規作成し、バリデーション・OTP・生年月日 UI などを段階的に改善した。

## 成果物

- `index.html` … フォーム本体
- `styles.css` … フローティングラベル・バリデーション表示・日付グループなど
- `app.js` … 入力補助・西暦/和暦連動・郵便番号検索・OTP・バリデーション

## 実装した項目

- メールアドレス（本人確認 OTP・4桁・`autocomplete="one-time-code"`）
- 氏名（漢字＝日本語 / ふりがな＝ひらがな / アルファベット＝半角英字）
- ミドルネーム切替（OFF: 2カラム / ON: 3カラム）
- 性別（男性・女性・その他）
- 生年月日（西暦・和暦連動、インプットグループ）
- 電話（携帯必須・固定・FAX、番号種別チェック）
- 住所（郵便番号 → zipcloud 連動）
- 銀行口座 / ゆうちょ（記号・番号）切替
- スマホ向け `inputmode` によるキーボード切替

## UI / UX の経緯

1. 通常ラベル → **フローティングラベル**
2. Bootstrap 風の成功（緑＋✓）/ 失敗（赤＋!）バリデーション表示
3. 生年月日を `| nnnn | 年 | nn | 月 | nn | 日 |` のインプットグループ化
4. バリデーションアイコンが「日」に重なる問題 → 右端専用枠（affix）で解消
5. 西暦・和暦の列幅を同一グリッドで揃え、和暦にも右端スペーサを付与
6. 「年」「月」「日」ラベルの着色・罫線を削除
